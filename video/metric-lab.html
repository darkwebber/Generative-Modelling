3 · challenges
  • half copied: fool five of six judges with a model that is 50% theft.
  • 99% static: precision collapses, yet recall stays high. Why? (Each static sample's nearest-neighbour ball is enormous, so it swallows real points: k-NN recall is fooled by outliers.)
  • perfect model + blur: slide blur up. Which judge complains first?
  • Mix 50% only-ones + 50% new: which metrics even notice half the model is a one-trick pony?
